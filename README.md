# Another Game Boy emulator? It's more important than you may think
As [Low Level Dev](https://www.youtube.com/@lowleveldevel1712) states in his step-by-step YouTube tutorial, on which the code you see here is based,

> _Some people may say it's a waste of time, there is plenty of emulator out there [...]_

But since it's 2026, I would also add

> _And there is already an AI agent that does it for you; maybe the free plan is way enough to accomplish the task._

Well, these claims got a point. But they miss two fundamental aspects: learning and enjoyment. Low Level Dev's first video goes:

> _Don't listen to the naysayers [...] enjoy it and learn how to code your own Game Boy emulator [...]_
